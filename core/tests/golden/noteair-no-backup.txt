    recovery holds the ram-environment, which step write-ram-environment writes instead.

Steps:
  1. back-up (back-up, in emergency) [safe stop]
     The backup is off: no disk is imaged. Only what is kept outside the disks (firmware boot settings, values unique to the device) is read.
     if it fails: previous-system-starts via transition emergency-by-hand
     if cut off after it: previous-system-starts via transition emergency-by-hand
  2. replace-boot-loader (write-boot-loader, in fastboot-stock) [untried, point of no return, safe stop]
     Replace the boot loader with GlassineOS's. From here there is no way back without the backup, and if this step fails only the emergency-mode cable helps.
     if it fails: special-hardware (emergency-cable) via transition cable-to-emergency
     if cut off after it: previous-system-starts via transition fastboot-to-android
  3. write-ram-environment (write-image, in fastboot) [untried, safe stop]
     Put the installer's helper on the device, in place of the stock recovery. The device restarts into it to write the rest.
     if it fails: previous-system-starts via transition fastboot-to-android
     if cut off after it: previous-system-starts via transition fastboot-to-android
  4. partition-table (write-partition-table, in ram) [untried, point of no return, safe stop]
     Give the device a second slot for GlassineOS. The data partition is made smaller: everything on it is deleted.
     if it fails: installer-can-finish via step partition-table
     if cut off after it: installer-can-finish via step write-kernel
  5. write-kernel (write-image, in ram) [untried, safe stop]
     Write the GlassineOS kernel to slot B.
     if it fails: installer-can-finish via step write-kernel
     if cut off after it: installer-can-finish via step write-base
  6. write-base (write-base, in ram) [untried, safe stop]
     Write GlassineOS to slot B.
     if it fails: installer-can-finish via step write-base
     if cut off after it: installer-can-finish via step write-vendor
  7. write-vendor (copy-partition, in ram) [untried, safe stop]
     Copy the device's own vendor files to slot B.
     if it fails: installer-can-finish via step write-vendor
     if cut off after it: installer-can-finish via step set-slot
  8. patch-stock-boot (patch-boot-image, in ram) [untried, safe stop]
     Change Android's start-up on slot A so it finds its own files on the new layout. If its start-up isn't one the installer knows, Android is left as it is and can't start.
     if it fails: installer-can-finish via step set-slot
     if cut off after it: installer-can-finish via step set-slot
  9. set-slot (set-boot-slot, in ram) [untried, safe stop]
     Start GlassineOS by default.
     if it fails: installer-can-finish via step set-slot
     if cut off after it: glassine-starts via transition ram-to-glassine
