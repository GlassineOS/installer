Status: refused
  - Secure Boot is on: the firmware would refuse to start GlassineOS, whose loader isn't signed for it. Switch it off in the firmware's set-up: restart the PC and open the set-up with the key it names while it starts (often F2, F10, Del or Esc; from Windows: Settings, System, Recovery, Advanced startup, Restart now, then Troubleshoot, Advanced options, UEFI Firmware Settings), set Secure Boot to Disabled (often under Boot or Security), save, and run the check again. Nothing else in the set-up needs changing. If Windows on this PC encrypts its disk (BitLocker or device encryption), have its recovery key at hand: Windows may ask for it after the change
